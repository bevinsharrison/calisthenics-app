Chin-ups — Ashura Protocol NOW SUPINATED
5 series · reps + dead hang · never let go
15 min▾
Same Ashura, now in supination
The endurance routine you've done in pull-ups, now with a supinated (underhand) grip — more biceps, balancing the forearms. Format is reps + dead-hang': e.g. "3-3'" = 3 chin-ups then 3s dead hang, never releasing. At least 2:30–3:00 rest between series.

Push the full L-sit
A pyramid this time (was EMOM) to reach longer holds. Objective: hold the full L-sit (both legs straight, horizontal) as long as possible each set. If you fail before the time's up, drop to tuck / one-leg / high-tuck to complete the hold — but try to stay in full L-sit to make progress. Rest by feel.
