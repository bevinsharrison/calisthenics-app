Pyramid · 2-2 → 8-8 → 2-2 · pull-ups + Aussie

The Belt — Pull Version
Each step: x pull-ups then x Australian pull-ups (e.g. "6-6" = 6 pull-ups + 6 Aussie). No rest between stages — 5–15s only if you truly need it. The 10-10 stage is removed (too high). To go further: switch to inverted pyramid, then push up to 10-10.
